# Spring Boot Product API

## Description
A Spring Boot application for managing products and categories.

## Build and Run

```
# Compile and build Docker image
mvn compile jib:build

# Run the application
mvn spring-boot:run
```

## API Documentation

## Features

- Product and Category management
- RESTful API
- Swagger documentation

## Requirements

- Java 17+
- Maven 3.6+
